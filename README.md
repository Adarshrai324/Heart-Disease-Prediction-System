# ❤️ Heart Disease Prediction System

## 📌 Overview
This project is an AI-based Heart Disease Prediction System developed using Machine Learning and Python. The system predicts whether a patient is likely to have heart disease based on medical attributes.

---

## 🚀 Features
- Heart disease prediction
- Data preprocessing
- Machine learning model training
- User-friendly prediction system
- Data visualization and analysis

---

## 🧠 Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Streamlit

---

## 📂 Dataset
The project uses heart disease datasets for training and testing the machine learning model.

Files used:
- heart.csv
- processed_heart_data.csv

---

## ⚙️ Project Workflow

1. Data Collection  
2. Data Preprocessing  
3. Data Analysis  
4. Feature Selection  
5. Model Training  
6. Prediction  
7. Result Evaluation  

---
